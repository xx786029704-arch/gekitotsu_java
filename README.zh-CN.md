**「激突要塞」集成工具箱**

[English](README.md) | 简体中文 | [日本語](README.ja.md)

激突Kit 在忠实复刻「激突要塞」物理引擎的基础上，提供批量对战推演、阵型工作台（含效果插件系统）、贡献分析、轨迹预测、单位图鉴与友情链接等功能，面向希望研究、验证并优化阵型的高端硬核玩家。

> 本项目为非官方粉丝作品，与游戏原作者无关，也未获得其授权或认可。

## 功能总览

| 模块 | 说明 |
|------|------|
| **对战模拟** | 多线程运行 1P 与 2P 阵营的全对阵对战，输出胜率统计。 |
| **贡献分析** | 从玩家阵型中删除 n 个单位，枚举或采样全部组合并批量对战，按胜率变化或每费变化排序。 |
| **阵型工作台** | 解码、编辑、预览与重编码阵容代码；查看单位与要塞信息；内置分析器；基于工作流的效果插件系统。 |
| **轨迹预测** | 在可缩放画布上可视化要塞运动与突击轨迹，支持表达式和自定义变量。 |
| **单位图鉴** | 浏览全部 63 个单位（id 0–62）的贴图、属性、描述、战术与最速行动计算。 |
| **友情链接** | 一键访问原作官网与中日社区资源。 |

- GUI：Java Swing + FlatLaf 3.5.4，支持深色/浅色主题与自定义主题色。
- 模拟引擎：零外部依赖，纯 `java.awt` 几何计算，逐帧复刻 Flash 原作。
- 界面语言：简体中文。

## 下载与运行

### Windows 发布包（推荐）

1. 从 Releases 页面下载最新的 `激突Kit vX.Y.Z.zip`。
2. 解压到任意目录。
3. 双击 `激突Kit/激突Kit.exe` 启动。镜像已捆绑 JRE 21 运行时，无需安装 Java 环境。

程序从工作目录读取 `1P.txt`、`2P.txt` 与 `config.ini`，输出 `result.txt` 和 `simple_result.txt`。首次运行会自动生成 `config.ini`。

### 从源码运行

环境要求：JDK 21+（Maven 可选）。

```bash
# 使用 Maven 构建可运行的 fat JAR
mvn package

# 运行 GUI（默认）
java -jar target/gekitotsu_java-1.8.0.jar

# 运行 CLI
java -jar target/gekitotsu_java-1.8.0.jar --cli
```

如需构建捆绑运行时的 Windows 可执行文件，请在项目根目录运行 `build_exe.bat`。首次使用前，请先修改脚本顶部的 `JDK_HOME` 与 `M2` 路径以匹配本机环境。产物位于 `dist/`：

- `dist/激突Kit/激突Kit.exe` — 自带 JRE 的应用镜像（嵌入图标）
- `dist/激突Kit v1.8.0.zip` — 发布压缩包

## 命令行模式

```bash
java -jar target/gekitotsu_java-1.8.0.jar --cli
```

CLI 读取 `1P.txt` 与 `2P.txt`（每行一个阵型，格式为 `名称&编码`），随后显示交互菜单：

| 选项 | 功能 |
|------|------|
| `0` | 开始全对阵对战，写入 `result.txt` / `simple_result.txt` |
| `1` | 设置单局帧数上限 |
| `2` | 切换血量积分记录 |
| `3` | 重新导入阵容文件 |
| `4` | 设置线程数 |
| `9` | 退出程序 |

## 功能详解

### 1. 对战模拟

运行 1P 与 2P 阵容的全对阵对战，输出胜率统计。

1. **编辑阵容** — 在「1P阵容」「2P阵容」标签页中粘贴阵容代码，编辑内容会以 500ms 防抖自动保存到 `1P.txt` 与 `2P.txt`。
2. **设置参数**：
   - **帧数上限** — 单局最大模拟帧数（默认 65536）。
   - **线程数** — 并行模拟线程数（默认等于 CPU 核心数）。
   - **血量积分** — 勾选后结果中显示剩余血量与血量积分。
   - **自动换行** — 勾选后结果文本自动换行。
3. **开始模拟** — 点击「开始模拟」，进度条与状态栏显示完成度与用时。
4. **查看结果** — 「详细结果」「简要结果」标签页展示 `result.txt` 与 `simple_result.txt` 的内容。

### 2. 贡献分析

量化每个单位的贡献：删除后胜率变化越大，该单位越关键。

1. **输入**：
   - **原始阵型** — 要分析的玩家阵型，可从 `1P.txt` 导入。
   - **测试阵集** — 作为评判基准的对手阵型集合，可从 `1P.txt` / `2P.txt` 导入或清空。
2. **参数**：
   - **探索率** — 随机采样的删除组合比例（100% 为全遍历）。
   - **删除数 n** — 每个组合删除的单位数量。
   - **线程数** — 工作线程数。
   - 参数旁的提示文字显示待模拟的组合数；组合数超过 1,000,000 时拒绝开始。
3. **开始 / 停止** — 先计算基线胜率，随后以滑动窗口逐步返回结果并显示预计剩余时间，可随时停止。
4. **结果**：
   - **单位汇总** — 每个单位的平均胜率变化与平均每费变化。
   - **组合排行** — 按胜率变化或每费变化排序的删除组合（点击表头切换排序）。n = 1 时仅显示单位汇总。
   - 选中一行后点击「复制」（或双击该行）即可复制删除对应单位后的阵型代码。

### 3. 轨迹预测

可视化要塞运动与突击轨迹，辅助研究弹道与突击规律。

- **列表（左侧）** — 轨迹、要塞壁、变量三个标签页：
  - 可手动添加轨迹，或从阵容代码中自动导入。
  - 变量 `a`–`z` 可在轨迹表达式中引用。
  - 单击选中、双击编辑、拖拽排序、Shift/Ctrl+点击多选、点击色块切换颜色。
- **画布（右侧）** — 滚轮以鼠标为锚点缩放（0.1x–5.0x），按住左键拖拽平移，右下角显示当前缩放比例。
- **快捷键** — `Delete` 删除、`Ctrl+C` 复制、`Ctrl+V` 粘贴、`Ctrl+X` 剪切、`Ctrl+A` 全选、`Ctrl+D` 取消选择；选中项以人类可读写文本格式复制，可跨列表粘贴。
- **轨迹参数** — 名称、突击壁 x、兵玉 x/y、1P/2P 加速度等级、突击段数、是否近突击壁、兵玉代码顺序、颜色。坐标支持含变量的整数表达式。

### 4. 阵型工作台

核心创作工具，采用三列布局：左侧输入/输出，中间预览，右侧信息与工作流。

#### 编辑与解析

- **输入区** — 粘贴阵容代码，下方实时显示解析后的阵型预览。
- **输出区** — 显示重新编码后的阵容代码。
- **➡ 按钮** — 将输出区内容复制到输入区，便于迭代修改。
- **中央预览** — 分层渲染阵型（要塞壁底层 + 兵玉上层），点击背景可自定义背景色。

#### 单位与要塞信息

- 预览面板下方显示选中单位的详细信息（名称、HP、CD、AT、cost、坐标）。在「单位列表」中点击单位条目即可切换选中。
- 「要塞信息」显示当前阵型名称、加速等级、总军资金等汇总信息。

#### 内置分析器

工作台自动检测以下问题并给出建议：

- **重叠检测** — 同种兵玉坐标过近或完全重叠。
- **突击最速检测** — 突击壁内的兵玉是否采用落地最速 x 坐标。
- **壁玉坐标建议** — 壁玉 x 坐标是否位于推荐位置（54 / 114 / 174 / 234 / 294）。
- **枪玉角度检测** — y = 349 的枪玉角度是否需要改为 2。
- **愈玉 / 缮玉位置检测** — 愈玉、缮玉是否在单位列表中过于靠后。

#### 工作流与效果插件

右侧栏可将一系列效果以工作流的形式应用到当前阵型：

- **效果库** — 用搜索框筛选，双击或拖拽效果添加到工作流面板。
- **节点操作** — 单击切换启用/禁用（●/×），双击编辑参数，右键打开菜单，长按拖拽排序，选中后按 `Delete` 删除。
- **错误提示** — 执行失败的节点显示红色边框与 ⚠ 图标，鼠标悬停查看错误信息。

#### 开发自定义效果插件

`effects/` 目录存放内置效果与插件 JAR。将 `.java` 源文件拖放到 `effects/build_plugin.bat` 上即可自动编译并打包为插件 JAR（需 JDK 21+）。`effects/samples/CopyAndRenameEffect.java` 是完整示例，演示了四种参数类型（`INT` / `STRING` / `BOOLEAN` / `UNIT_ID`）与 `validate` / `execute` 接口实现。详见 `effects/samples/README.md`。

### 5. 单位图鉴

浏览全部 63 个单位（id 0–62）：

- **左侧列表** — 点击条目切换查看。
- **右侧详情** — 贴图（100×100）、名称、编码、自适应换行的属性标签（HP / CD / AT / cost 等）、`unit_details.json` 扩展描述区，以及**最速行动计算面板**：输入突击壁 x 坐标与「兵玉代码在前」选项，自动计算该单位在突击中的最速出手 x 坐标集。
- 最速行动面板仅对 `cd >= 0 && shoot >= 0` 且非墙类单位显示。

### 6. 友情链接

分类展示激突要塞相关资源，点击后自动打开浏览器：

- **原作官网** — 激突要塞！公式サイト
- **国内社区** — 百度贴吧、激突驿站、萌娘百科、比赛 QQ 群
- **日本社区** — Discord 频道、青茶の要塞研究所、wikiwiki、Seesaa 攻略 wiki、掲示板

## 阵容编码格式

### 文件格式

`1P.txt` / `2P.txt` 每行一个阵型：

```
阵型名称&编码
```

### 编码

61 进制，字符表为：

```
0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ
```

即 `0-9`、`a-z`、`A-Z`，共 61 个字符。

每个单位编码包含单位 id 与 x / y / 半径角度；首位核心类型后的 5 个字符描述核心坐标。HP 信息可以 `#` 分隔符接在代码末尾。`Main.compileFort()` 负责解析，`to_xyr()` 解码坐标，`Formation.encodeHp()` / `decodeHp()` 处理 HP 编解码。

### 文件编码

输入文件可能是 UTF-8 或 GBK，程序会自动检测 BOM 并正确读取。输出统一使用 UTF-8。

## 常见问题

**Q1：启动后提示「formula.json 未找到」。**
资源文件缺失。从源码运行时，请确保 `target/classes` 下包含 `src/main/resources` 的全部资源（运行 `build_exe.bat` 会自动复制，IDEA 通常也会自动处理）。

**Q2：模拟结果异常。**
检查阵容代码格式（`名称&编码`）与单位坐标是否合法，可先用阵型工作台的解析功能验证。

**Q3：效果插件不生效。**
确认插件 JAR 位于 `effects/` 目录，且实现了 `Effect` 接口并通过 `ServiceLoader` 注册，参考 `effects/samples/CopyAndRenameEffect.java`。文件名以 `_` 开头的插件处于禁用状态。

**Q4：切换主题后部分界面未更新。**
切换主题会自动刷新所有标签页；若仍有异常，重启程序即可。

**Q5：如何打包成 EXE？**
运行项目根目录的 `build_exe.bat`，产物位于 `dist/`：

- `dist/激突Kit/激突Kit.exe` — 应用镜像
- `dist/激突Kit v1.8.0.zip` — 发布压缩包

首次构建较慢（需生成 JRE runtime），后续构建会复用 `dist/runtime_cache` 加速。
